CHIP-8 Emulator

An implementation of the CHIP-8 emulator in C

  • Emulated the CHIP-8 CPU architecture in C using the SDL library to render graphics.
  • Fetch / Decode / Run cycle implementing all 35 CHIP-8 opcodes.
  • Debugging mode allowing users to step through each emulation cycle, printing registers and flags.

TCP File Server

A simple server and client I made to download files from laptop to laptop on my local network.

  • Developed a simple TCP server that supports multiple clients to download up to 10 files in one connection.
  • Followed network programming best practices by creating an IP agnostic server, and converting back and forth from host to network byte order when sending / receiving.
  • Sends file information in stages allowing for accurate reconstruction of files. Implementing chunked buffer sending for very large files (8GB+) soon TM.

Image to Ascii

A fun little command line program to take an image and turn it into ascii art

  • Used the std_image library to decode supported file types.
  • Grabbed terminal and image dimensions for scaling and calculating downsampling amount.
  • Grayscaled pixel data, applied gamma correction, and printed the applicable symbol to the terminal, and to the out file.

Custom Memory Allocator

Making my own little memory allocator via mmap for educational purposes.

  • Create a heap for dynimcally allocated memory via a memory map. Initialized and destroyed appropriately.
  • Includes the malloc() function family and free() to manage dynmically allocated memory as expected.
  • Includes memory coalescing for efficient memory allocation, alignment of memory, and helper functions such as memcopy() and memset().
